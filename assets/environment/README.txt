Toque de Campo — original environment kit

Geometry, procedural material recipes and textures were created specifically for
this project. No external model pack, Battlefield asset, background replacement,
or downloaded environment texture is used here.

Regenerate the 256 x 256 seamless surfaces with:
  tools/generate_environment_textures.py

Each surface has albedo, tangent-space normal and roughness maps.
Surface families: concrete, plaster, painted steel, wood, cardboard, sand, rock,
canvas/fabric, tiled industrial floor, asphalt and brick.

The existing weapon assets, music and menu photographs retain their existing
credits and licenses; this file applies only to this new environment directory.
