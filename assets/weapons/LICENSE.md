# Weapon models

The following Godot GLB files are adapted from Polyy.AI's **3D Low-Poly Guns Pack (low-poly LOD)**:

- `glock.glb` — Compact Polymer Pistol
- `ak.glb` — Wood-Furniture Assault Rifle (AK-style rifle, previously mislabeled as FAL)
- `sniper.glb` — Bolt-Action Sniper Rifle

Source: [Polyy.AI on itch.io](https://polyyai.itch.io/3d-low-poly-guns-pack)

The pack is released under **CC0 1.0 Universal**. These three models were copied into the project and their forward axis was adapted in code. The source README notes the models were generated with polyy.ai; the itch.io page labels the pack AI-assisted.

The separate FAL is original procedural geometry in `scripts/fal_model.gd`, modeled for this game from photographic references. It does not use the AK mesh or downloaded third-party FAL geometry.
